## About

This project was developed during college in partnership with **iFood**, with the goal of building a web platform for **iFood partners**. The application allows restaurants and partner establishments to receive customer feedback and manage their accounts directly through the app, centralizing financial and performance data in one place.

The project was key to consolidating front-end development skills, especially in building structured and styled web interfaces with **HTML and CSS**.

---

## Technologies

- **HTML** — Page structure and markup
- **CSS** — Styling, layout and responsiveness

---

## Features

- **Financial Dashboard** — View data and metrics for the partner account
- **Feedback Management** — Receive and track customer reviews
- **Account Management** — Control establishment information
- **iFood-Inspired UI** — Design faithful to the platform's visual identity

---

## Project Structure

```
iFood-Finance/
├── assets/        # Images and visual resources
├── css/           # Stylesheet files
├── pages/         # HTML pages
└── index.html     # Main page
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/VryDeveloper/iFood-Finance.git
   ```
2. Navigate to the project folder:
   ```bash
   cd iFood-Finance
   ```
3. Open `index.html` in your browser.

> No installation or dependencies required — this is a 100% static front-end project!

# iFood Finance 🍔💰

## Sobre o Projeto

Este projeto foi desenvolvido durante a faculdade em parceria com o **iFood**, com o objetivo de criar uma plataforma web voltada para **parceiros do iFood**. A aplicação permite que restaurantes e estabelecimentos parceiros recebam feedbacks dos clientes e gerenciem suas contas diretamente pelo app, centralizando informações financeiras e de desempenho em um só lugar.

O projeto foi fundamental para consolidar conhecimentos em desenvolvimento front-end, especialmente na criação de interfaces web estruturadas e estilizadas com **HTML e CSS**.

---

## 🛠️ Tecnologias Utilizadas

- **HTML** — Estrutura e marcação das páginas
- **CSS** — Estilização, layout e responsividade

---

## ✨ Funcionalidades

- 📊 **Dashboard Financeiro** — Visualização de dados e métricas da conta do parceiro
- 💬 **Gestão de Feedbacks** — Recebimento e acompanhamento de avaliações dos clientes
- 👤 **Gerenciamento de Conta** — Controle das informações do estabelecimento parceiro
- 🎨 **Interface Inspirada no iFood** — Design fiel à identidade visual da plataforma
